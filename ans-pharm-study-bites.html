6. Tracing-Question Logic (high-yield reasoning, not memorization)

  • BP ↑ → reflex HR ↓ (baroreceptor reflex); BP ↓ → reflex HR ↑
  • Ganglion blockers abolish the reflex HR change entirely
  • If adding an α-blocker changes the drug's BP/HR effect → original drug had α-agonist activity
  • If adding a β-blocker changes the drug's BP/HR effect → original drug had β-agonist activity
  • If α-blocker removes the BP rise but HR is still elevated → drug has intrinsic β1 activity (not just reflex)
  • If α-blocker removes the BP rise and HR normalizes → the tachycardia was purely reflex
  • Isolated tissue/organ prep (not in vivo) → no reflex change possible
  • Epinephrine reversal: α-blocker pretreatment flips epinephrine's pressor response to a depressor response (unmasked β2 vasodilation)
