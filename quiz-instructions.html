The short version

Each block of material (MSK II Exam 1, MSK II Exam 2, and so on as new blocks are added) has its own question bank file. Download the file for the material you want to be quizzed on, then follow the steps below.

Steps

  1. 1

    Find the file for your material

    Question banks are named for the exam block they cover — for example MSK2 - Exam 1 Question Bank.json. As more blocks get added over time (Exam 2, others), they'll all follow the same pattern.

  2. 2

    Download the file

    Click Download on its card in the library section below. It will save as a .json file to your device's downloads folder — you don't need to open it or interact with it yet.

  3. 3

    Open the quiz engine

    Go to the quiz engine site. If this is your first time using it, the question bank will be empty — that's expected. The engine itself never changes; only the file you load into it does.

  4. 4

    Upload the file into the quiz engine

    In the quiz engine, go to the Manage Bank tab. Drag the .json file you just downloaded straight onto the drop zone, or click it to open a file picker instead. The file is read directly — no need to open it, copy anything, or paste.

    Once it's imported, every topic in that file becomes available to quiz yourself on — you'll be able to pick specific topics, set how many questions you want, and shuffle the order.

  5. 5

    Start a quiz

    Head to the New Quiz tab, select the topics you want covered, and go. Your results screen will break down performance by topic, and you can retry just the questions you missed.

Switching to a different block of material

Since new question banks will keep getting added over time (Exam 2, future courses, etc.), you'll likely want to swap what's loaded in the engine depending on what you're currently studying. Here's what to do:

If you want to…Do this
Study a new block for the first timeDownload that block's file → import it in Manage Bank
Switch from one block to anotherClear the current bank in Manage Bank → import the new file
Study multiple blocks togetherImport more than one file — questions stack, and topics from both stay separately selectable
One thing to keep straight

The file name tells you what material is inside — always check that the file you're downloading actually matches what you intend to study before importing it. Importing the wrong block by accident is an easy mix-up to make.

Common questions

Do I need to unzip or open the JSON file myself?

No. Leave it exactly as downloaded and drag it straight onto the drop zone (or pick it via the file button) — the engine reads it directly from disk.

Will importing a new file erase my old one?

No — imports add to what's already loaded. If you want a clean slate for a new block instead of a combined bank, clear the bank first in Manage Bank before importing.

Does my progress get saved if I close the tab?

Yes — the question bank you've imported is saved in that browser's local storage, so reopening the quiz engine file in the same browser on the same device will have it ready, no need to re-import. It won't carry over to a different browser, a different device, or an incognito/private window, and it can be cleared if you clear that browser's site data.

What if the import doesn't work?

The quiz engine will tell you specifically what went wrong — for example, if the file looks incomplete, or if it can't find valid question data at all. If you see an error, try re-downloading the file (an incognito/private browser window helps if an extension is interfering with your downloads) and dragging it in again. Pasting the file's contents directly into the text box below the drop zone still works too, as a fallback.

What if a topic I expect isn't showing up?

Double-check you imported the right file for that material — a topic can only appear in the engine if it exists in a file you've actually uploaded.
